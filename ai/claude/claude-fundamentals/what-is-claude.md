# What Is Claude?

## About

Claude is an AI system made by Anthropic. We can use it to read, write, reason through problems, work with code, and understand images or documents.

At its simplest, Claude is a conversation partner: we give it a question or some material, and it responds. But it becomes much more useful when we give it a real task, the right context, and a clear definition of a good result.

## A Simple Example

Instead of asking:

> Explain this error.

You can ask:

> Read this error and the related method. Tell me the likely cause, show the smallest safe fix, and suggest one test that would catch it next time.

The second request gives Claude a job, a boundary, and a useful outcome to aim for.

## What Claude Can Help With

Claude works well when there is information to understand or transform.

* **Writing and analysis** — summarising a document, comparing options, drafting an explanation, or turning notes into a plan.
* **Software work** — reading code, debugging, suggesting changes, writing tests, and reviewing a pull request.
* **Documents and images** — extracting information from PDFs, screenshots, diagrams, and other visual inputs.
* **Structured outputs** — producing a checklist, table, JSON response, or another defined format.
* **Tool-based work** — using connected tools or services when they are available and permission has been given.

{% hint style="info" %}
The quality of the answer depends heavily on the context we provide. A useful prompt is not necessarily long; it is specific about the task, the relevant information, and what “done” looks like.
{% endhint %}

## Claude Is Not Magic

Claude predicts and reasons from the information it receives. It can make mistakes, miss important context, or sound confident when an answer needs checking.

For anything that matters, keep a human in the loop:

* Check facts against the original source.
* Run the tests before accepting code changes.
* Review security-sensitive or production-facing work.
* Ask Claude to explain its assumptions when the answer is unclear.

This is not a weakness unique to Claude. It is simply the right way to work with AI: use it to move faster, then apply engineering judgment.

## Claude Is More Than One Interface

We may meet Claude in several places:

| Where we use it   | What it is useful for                                      |
| ----------------- | ---------------------------------------------------------- |
| **Claude.ai**     | Chatting, research, analysis, writing, and artifacts       |
| **Claude Code**   | Working directly in a codebase from the terminal or editor |
| **Claude Cowork** | Completing file-based tasks and supervised workflows       |
| **Claude API**    | Adding Claude to your own product or automation            |

They are different ways of using Claude, not unrelated products. The same ideas- clear instructions, useful context, tool access, and verification apply everywhere.
